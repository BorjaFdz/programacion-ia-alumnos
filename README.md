# programacion-ia-alumnos
Repositorio de material, ejercicios y prácticas de los módulos de **Programación** de la especialización en **Inteligencia Artificial y Big Data**.

El contenido se irá publicando progresivamente durante el curso.

## Cómo descargar el repositorio

La primera vez:

```bash
git clone https://github.com/BorjaFdz/programacion-ia-alumnos.git

```
Después entra en la carpeta:

```bash
cd programacion-ia-alumnos
```

## Cómo actualizar el material

Durante el curso se irán añadiendo nuevos ejercicios, notebooks y recursos.

Para descargar los cambios:

```bash
git pull
```

Conviene ejecutar este comando al comienzo de cada clase.

## Uso de Inteligencia Artificial

La IA forma parte de las herramientas que utilizaremos durante el curso.

Podrás utilizarla cuando se indique, pero no sustituye la comprensión del problema.

Cuando utilices IA debes ser capaz de:

- explicar el código generado;
- detectar posibles errores;
- modificarlo;
- justificar las decisiones tomadas;
- comprobar que la solución realmente responde al problema;
- defender tu trabajo sin depender de la IA.

Si no puedes explicar una solución, no puedes considerarla una solución propia.
